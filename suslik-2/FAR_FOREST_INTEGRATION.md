# Работа в дальнем лесу — изолированная поставка (SUSLIK 2)

**Ветка-основа**: `suslik-2/intro-v1`. По состоянию на 13 октября 2026 в ней есть отдельная тестовая карта, но нет опубликованного исполняемого кода лесопилки, оплаты смен, разговора с бригадиром, сезонных показателей и сна. Этот PR специально НЕ пытается реконструировать их. Полный игровой маршрут пока не подключён и не проверен. Никаких изменений вне `suslik-2/`.

## Авторские материалы

- `assets/far-forest/goblin-encounter.png` — предоставленный рисунок 1672×941. Изображение сохранено **без потери пикселей** (непрозрачный RGBA переведён в RGB PNG для загрузки GitHub); это не другое/сгенерированное изображение.
- `far-forest-content.js` содержит исходный русский текст слово в слово, RU/EN кнопки, альтернативные подписи, путь к PNG, тексты временных заглушек. Корректировка контента и путей не требует изменения движка.
- Стандартное сезонное изображение **должна передать настоящая лесопилка** как `seasonalImage`; его нельзя заменить чужим изображением на глаз.

## API (обычные `<script>`, работают локально с `file://`, без fetch/Node.js)

В актуальном переносимом HTML лесопилки, когда он будет доступен, подключить в таком порядке:

```html
<script src="far-forest-core.js"></script>
<script src="far-forest-content.js"></script>
<script src="far-forest-ui.js"></script>
<link rel="stylesheet" href="far-forest.css">
```

Если HTML лежит в другом каталоге, относительные пути меняются, но сами файлы и механика не требуют сервера.

### Открытие

Создать в существующем сохранении **текущего захода** поле `farForest` со значением `SUSLIK2FarForest.initialState()`, восстанавливая через `restoreState(saved.farForest)`. При завершении обязательного разговора (не при просто достижении 15 смен) вызвать:

```js
const ff = SUSLIK2FarForest;
ff.unlockAfterForeman(run.farForest, {
  paidShifts: run.paidSawmillShifts, // фактически ОПЛАЧЕННЫЕ смены, из реального кода
  strength: run.character.stats.strength,
  endurance: run.character.stats.endurance,
  foremanConversationCompleted: true
});
// сохранить существующим способом
SUSLIK2FarForestUI.addAccessButton(sawmillControls, run.farForest, openFarForest, {locale: run.locale});
```

После получения доступа кнопка остаётся открытой на текущий заход; повторная проверка статов после разговора не нужна. Не показывать кнопку, пока авторский разговор реально не завершён.

### Одна попытка, независимое 50/50

```js
const a = ff.beginAttempt(run.farForest); // ровно один Math.random() для каждой попытки
if (!a) return; // доступ закрыт либо предыдущая попытка ещё не разрешена
if (a.outcome === ff.OUTCOMES.GOBLIN) {
  // НИЧЕГО не списывать: ни энергию, ни деньги, ни время
  showScene(run.farForest.sceneId);
} else {
  // см. следующий раздел: сначала атомарно применить смену, потом рисовать кнопки
}
```

`ff.beginAttempt` возвращает `null`, если предыдущая обычная смена ещё не оплачена или встреча не разрешена. «Продолжить работу» разрешается только для уже оплаченной обычной смены; каждый вызов снова бросает независимый 50/50.

### Обычная смена и оплата один раз

`settleOrdinaryShift(farForestState, gameState, calculateApprovedShift)` **не списывает самостоятельно ничего**: настоящий расчёт остаётся за существующей лесопилкой, переданной как чистая функция. Её контракт — принять текущий `gameState` и команду `{attemptId, energyCost:1, extraGold:10, paidShift:true, standardSeasonalStats:true, standardSawmillWage:true}`; вернуть НОВЫЙ `gameState` с −1 энергии, стандартными сезонными изменениями, стандартной утверждённой зарплатой и дополнительно +10 золотых, с одним учётом оплаченной смены и сохранением обязательных событий 15/50. Сама функция не должна мутировать аргумент или выполнять внешние платежи. **Не создавать вторую формулу сезонных эффектов.**

```js
const result = ff.settleOrdinaryShift(run.farForest, game, calculateApprovedShift);
if (result) {
  // записать ВМЕСТЕ в одно атомарное сохранение, используя штатную систему игры:
  game = result.nextGameState;
  run.farForest = result.nextFarForestState;
  saveGame();
}
// только после успешного сохранения — показать сезонное изображение и две кнопки
SUSLIK2FarForestUI.renderScene(view, {
  farState: run.farForest, seasonalImage: currentStandardSawmillSeasonImage(), locale: 'ru',
  onNext: returnToExistingSawmillFlow,
  onContinue: startNextFarForestAttempt,
  onGoblinChoice: handleGoblinChoice
});
```

Повторный вызов `settleOrdinaryShift` с тем же оплаченным `attemptId` возвращает `null` даже после чтения сохранения. Чистая функция + атомарная запись двух состояний обязательны для устойчивости к сбоям. Если штатная лесопилка уже вычитает энергию, **не вычитать её второй раз**. `onNext` подключить к реальному существующему продолжению смены: в опубликованной основе оно отсутствует.

### Встреча с гоблином

UI показывает авторскую картинку/текст и кнопки «Получить разрешение», «Бой». Их обработчик только вызывает:

```js
const sceneId = ff.chooseGoblinPath(run.farForest, 'permission'); // или 'fight'
// сохранить и показать заглушку с sceneId
```

Постоянные ID: `far-forest-goblin-encounter`, `far-forest-permission-pending`, `far-forest-fight-pending`. Встреча НЕ оплачивается и не тратит энергию или время. Никаких последствий, нового диалога, боя либо автоматического возврата из заглушек в этом PR нет. Следующий сценарий предоставит автор.

## Локальные проверки

`node --test tests/far-forest.test.mjs` (Node используется **только для тестов**, не для запуска игры). Тесты проверяют доступ, границу 0.5, распределение 50/50, независимость последовательных попыток, один платёж, восстановление сохранения, две ветки гоблина и отсутствие `fetch` / модульных импортов в новых browser JS. Поскольку реального движка лесопилки в опубликованной ветке нет, end-to-end тест полного игрового маршрута не заявлен.
