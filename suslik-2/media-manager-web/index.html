03 Публикация

Для публикации нужен доступ к Plegyer/Text. Получить токен GitHub ↗ (Contents → Read and write). Токен не стирается после публикации; хранится только в открытой странице до её обновления или закрытия.

Посмотреть опубликованные изменения ↗
Публикуются только выбранные файлы одного события. Остальная игра и другие сцены не меняются. Новые файлы входят в следующую сборку SUSLIK 2. Будущие неготовые сцены отмечены отдельно.
