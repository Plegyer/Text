# MUSIC.PREWORLD.001

В SUSLIK 2 для всего пролога используется `Clockwork Cupcake.mp3` — оригинальный файл `Clockwork Cupcake(1).mp3`, предоставленный автором 12.10.2026. Файл скопирован без перекодирования. Назначение сцены и путь задаются в `content/music.json`, управление воспроизведением — в `music-director.mjs`.

Трек играет на заставке, создании персонажа и во всех сюжетных окошках вплоть до последнего «Далее». При переходах не перезапускается и на экране `game-main` останавливается. Браузер может ждать первого нажатия пользователя, прежде чем начать воспроизведение.
