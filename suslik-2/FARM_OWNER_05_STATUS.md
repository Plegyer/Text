# SUSLIK 2 — встреча хозяина фермы после пятой оплаченной смены (16.10.2026)

**Разрабатывается непосредственно в канонической ветке** `suslik-2/portable-canonical-20261015` (никакой самостоятельной игры/другого движка).

## Авторские правила

После **пятой оплаченной смены** на ферме зомби обязательно и один раз за прохождение открыть сцену `undead-farm-owner-05`. Сцена использует обычный cue `farm`, показывает точно предоставленный автором диалог и только кнопку «Далее», возвращающую к **уже оплаченному** результату пятой смены. Новых списаний энергии/золота, повторного начисления, предметов или концовок нет. `run.farmOwnerMet` сохраняется и восстанавливается.

Точный текст автора находится в `gameplay-content.js` (`text.undeadFarmOwner05`). Код — `gameplay-ui.js`, `gameplay-system.js`, `offline.js`; данные — `content/scenes.json` и `content/offline-content.js`. Тесты — `tests/undead-farm-owner.test.mjs`.

Он указан под целевым путем `assets/events/undead-farm-owner-05.png` в коде, но **само новое изображение в GitHub пока не загружено**. Оно было предоставлено автором в текущем чате и присутствует в локальной игре. Старые сезонные PNG и музыка не заменяют изображение встречи. Не сообщать пользователю, что новое изображение опубликовано, пока его Git blob не подтверждён.

Полностью рабочий старый код с ассетами находится **только в канонической ветке**, не в прежних черновиках. Код встречи был перенесён туда выборочно из `suslik-2/farm-owner-meeting-20261016` через Git tree, с сохранением всего оригинального `assets/` и без изменений `main`.
