# SUSLIK 2 — окно работы на ферме зомби, передача и границы (15.10.2026)

**Последнее указание автора:** подключить окно работы фермы по образцу окна лесопилки. Обычные результаты смен: четыре предоставленных изображения в порядке **лето → осень → зима → весна**. Кнопки **«Работать»**, **«Продолжить работу»**, **«Вернуться домой»** (последняя ведёт на карту). Музыка фермы **передана автором**: `The_Ghoul_s_Night_Shift.mp3` (SHA-256 `0359e9335bce8881b672d338667c806e36b2c1199e58f82821da7b159c2f9d8d`), должен воспроизводиться через прежний музыкальный директор как cue `undead-farm`; исходные байты пока **не опубликованы** в GitHub.

## Действительно опубликовано в GitHub

- `undead-farm-core.js`: единая чистая расчётная функция смены на ферме; её данные передаются **общему хосту работы** через `commitOrdinaryPaidShift`. Сама функция не создаёт отдельного Save или календаря, не списывает деньги сама, не запускает повторно награду. Присутствует защита против повторного receipt ID на стороне хоста; хост обязан атомарно проверять IDs.
- `undead-farm-ui.js` и `undead-farm.css`: повторно используемое рабочее окно с сезонным художественным изображением, просмотром ожидаемой оплаты, статами энергии, кнопками «Работать» (без немедленного автозапуска при входе), «Продолжить работу» после оплаты, «Вернуться домой» на карту; адаптивно для узких экранов, кнопки блокируются при нехватке энергии.
- `map.html`, `map.mjs`, `map.css`: клик `undead_farm` теперь открывает указанное окно на **старой отдельной тестовой карте**. Это **не последняя рабочая сборка**. Если игровой хост `globalThis.SUSLIK2GameplayHost.undeadFarm` ещё не подключён, окно видно, «Вернуться домой» закрывает его, а «Работать» **не генерирует фальшивые деньги/смены**.
- `tests/undead-farm.test.mjs`: проверяет числовые сезонные изменения, формулу зарплаты (до сезонных изменений), минимум 1, шансы Похоти, одиночную оплату, отсутствие предметов и концовок, контракт хоста и кнопки.
- `content/undead-farm-seasonal-images.json`: авторская таблица соответствия 4 исходных PNG с размерами и SHA256. **Байты четырёх новых PNG в GitHub не опубликованы**; сезонные пути сейчас зарезервированы, а UI показывает предупреждение, если PNG не найден. Загрузка и проверка их публикации — отдельный незакрытый шаг.

## Правила одной оплаченной смены

- Ферма доступна с начала игры, смена только после нажатия **«Работать»**, списывает **1 энергию**. Если энергии нет, работать нельзя.
- Выплата: `min(120, Math.round(37 + 0.3×Выносливость + 0.3×Магия + 0.2×Разум))` золотых. Для сохранения существующей механики берутся значения **до** сезонных прибавок. Это числа изученного старого исходника, принятые как основа; будущие прямые числовые изменения автора имеют приоритет.
- Сезоны: весна +1 Выносливость/+1 Магия/−1 Разум; лето +1 Выносливость/+1 Сила; осень +1 Выносливость/+1 Разум/−1 Сила; зима +1 Магия/+1 Разум. Характеристики **не ниже 1**; верхний cap должен быть взят из действующего игрового хоста, в том числе возможен 200. В `receipt(...)` для правильной отображаемой дельты можно передать `statCaps`.
- **Предметы и бонусы-инвентарь не вводить**, даже если они были в старом проекте. `itemsAdded=[]` всегда; **концовки не вводить**. Hard Work признана только как будущее направление, не реализуется сейчас.
- **Единая Похоть для всех работ:** если Похоть ниже 25 — обычная картинка; иначе 25–100% шанс альтернативного оплаченного результата; каждое третье общее срабатывание +1 Похоть, без дополнительной смены/энергии/денег. Использовать из хоста `lustActivationCount`, не новый карьерный счётчик. Автор ещё не дал альтернативные изображения фермы; слот `undead-farm/shift/lust-pending`, с нейтральной заглушкой, без самовольного текста.
- Один `receiptId` на каждую смену, единственная оплата и запись; после reload показывать сохранённый `farmView` и `farmLastReceipt`, а не пересчитывать RNG. Не допускать двойного счётчика за платную смену. Доступ к ночи, карте и день недели остаются у существующей единой игры.
- **Музыка**: музыкальный файл теперь предоставлен автором и зарегистрирован в `content/undead-farm-audio.json`, но **ещё не загружен на GitHub**. UI отправляет `requestMusicCue('undead-farm')` через необязательный метод общего хоста при первом открытии окна. Музыкальный директор должен связывать cue с целевым `assets/music/The_Ghoul_s_Night_Shift.mp3` и не перезапускать проигрывание при выборе очередной смены/экрана результата. Сам UI не создаёт `Audio` и не управляет отдельным звуковым потоком.

```js
  goToMap: () => { /* existing host map scene */ }

```

`commitOrdinaryPaidShift(receipt)` должен в **одном транзакционном изменении** старого Save проверить `receiptId`, снять 1 энергию, начислить ровно `goldEarned`, применить `statsDelta` и `lustDelta` с cap/floor, записать **общий** счётчик Похоти `lustActivationCountAfter`, увеличить счётчик **оплаченных смен фермы** на 1, сохранить сцену результата и идентификатор смены. Вызов по повторному `receiptId` должен быть безопасным no-op. `setFarmView('result')` не пересчитывает смену и не выдаёт повторную награду.
