# SUSLIK 2 — текущее состояние

## Утверждено автором
- SUSLIK 2 — отдельный проект; старый `Plegyer/Text` / Portal Life не изменять.
- Заставка — предоставленное автором изображение «Проект: Белый суслик», встроенное в сцену.
- Внизу через пару секунд появляется «Старт», открывающий выбор характеристик.
- Переходы сами по себе не тратят ресурсы; не создавать неутверждённый баланс и сюжет.

## Реализованный отрезок
- `splash` → «Старт» через 2200 мс → `character-selection`.
- Сцены и переходы описаны в `content/scenes.json`.
- Состояние экрана хранится отдельно в `localStorage`: `suslik2.save.v1`.
- Меню характеристик содержит только заголовок, неутверждённых параметров нет.

## Запуск
`npm start` из `suslik-2`, открыть http://127.0.0.1:4173/. Заставка заново: `/?restart=1`. `npm test` проверяет структуру сцены.
