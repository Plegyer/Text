# SUSLIK 2 — первая концовка и Старт+

Область изменений: только `suslik-2/`, без старого проекта.

## Интеграция реальной лесопилки

На исходной GitHub-ветке `suslik-2/intro-v1` (13.10.2026) нет реализации лесопилки, 15/50 смен, сна или энергии. Здесь реализованы экраны, состояние, проверки и точка подключения, но **не** имитируются смены и обязательное событие. Когда актуальная реализация лесопилки будет доступна, добавить вызовы в её коде, сохранив текущую механику:

1. `recordSawmillShift(state)` — после успешной завершённой смены, в сцене `sawmill`.
2. `markSawmill50EventSeen(state)` — только ПОСЛЕ фактического завершения обязательного события 50-й смены.
3. `returnFromSawmillToMap(state)` — непосредственно при возврате из лесопилки на карту.
4. Сохранять state через существующий persist() после каждого шага.

Меню НЕ доступно по одному счётчику 50; сначала необходимо обязательное событие, потом выход из лесопилки. Автоматически завершать событие по номеру смены нельзя. Игровая карта: `map.html?game=1`, независимая карта-предпросмотр `map.html` остаётся read-only.

## Сохранения и бонусы

`localStorage['suslik2.save.v1']`, схема v3 с миграцией v1/v2. Полученные концовки хранятся в `meta.unlockedEndings` (например, `['hard-worker']`) и переживают сброс текущего захода. `Старт+` вычисляется из наличия открытых концовок, отдельно не хранится. `selectedBonuses: string[]` — множественный независимый выбор текущего захода, без ограничений на минимум/максимум. `run.bonusesApplied` защищает от повторного начисления при перезагрузке, а `hard-worker` даёт ровно +5 силы при подтверждении выбора. Прогресс `run.sawmillShifts`, `run.sawmill50EventSeen` и `run.endingOfferOnMap` сбрасывается при завершении захода, не трогая мета-награду.

## Сценарий после подключения реальной лесопилки

50 смен → обязательное событие → выход на карту → «Ну что ж...» → «Трудяга» → «Конец» → заставка с доступным «Старт+» → характеристикам → бонусы (можно ничего не отметить) → следующий заход. «Отказаться» всегда ведёт на карту. Unit-тесты: `npm test`.
