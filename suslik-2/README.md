# SUSLIK 2

Изолированный игровой срез. Старый Portal Life остаётся без изменений.

## Запуск
Нужен Node.js 20+. В папке `suslik-2` выполните `npm start`, затем откройте http://127.0.0.1:4173/. Установка зависимостей не требуется. Кнопка «Старт» появляется через 2,2 секунды после заставки и ведёт в раздел «Выбор характеристик».

## ВАЖНО: изображение в архиве
Ветку GitHub пока нельзя считать полным игровым дистрибутивом: из-за ограничения загрузки бинарного файла через доступный интерфейс **авторская картинка не включена в коммит**. Полностью рабочая сборка с оригинальной картинкой передана отдельным ZIP-архивом. Для запуска этой ветки с авторской заставкой скопируйте `assets/splash-title.png` из архива в эту папку.

## Проверка с начала
Для повторного показа заставки откройте http://127.0.0.1:4173/?restart=1. Сбрасывается только сохранённый экран SUSLIK 2, а не старая игра. Ключ `suslik2.save.v1`.

## Изменение контента
Экраны, подписи, задержка кнопки и переходы — в `content/scenes.json`; изображение — `assets/splash-title.png`. Код движка — `src.js`. Характеристики, числа и правила распределения ещё не описаны автором.
