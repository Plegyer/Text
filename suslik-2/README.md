# SUSLIK 2 — переносимая сборка v18 (лесопилка)

Для Windows: распакуйте **весь** архив, затем дважды щёлкните `PLAY SUSLIK 2.cmd` в папке `suslik-2`. Node.js и Интернет не нужны. Для обновления существующей установки с одним ярлыком используйте `INSTALL OR UPDATE SUSLIK 2.cmd`, предварительно закрыв игру. Старый Portal Life не затрагивается.

В сборке сохранены оригинальные вступление, музыка `Clockwork Cupcake.mp3`, GIF и карта `Plegyer/Text`, ветка `suslik-2/intro-v1`, коммит `f5ec253`. Начальные доступные локации: лесопилка, бар сатиров, ферма нежити и школа; остальные закрыты. Содержимое остальных локаций ещё не создано.

**Лесопилка:** при похоти ниже 25 нажатие на здание сразу выполняет одну рабочую смену. Отображается оригинальная сезонная иллюстрация (лето — топор, весна — дрова, зима — пила, осень — укладка брёвен), −1 энергия, изменение характеристик и зарплата. Кнопки «Продолжить смену» (ещё одна смена и платёж) и «Вернуться в город» (на карту без расходов). При отсутствии энергии смена невозможна. Смена не меняет день/сезон. Сезоны определяются календарём из прежнего движка: по 10 игровых дней с весны.

Формула старого `lumber.shift`: `min(120, round(35 + Сила * 0.5 + Выносливость * 0.25))`; заработок вычисляется перед сезонными эффектами. Статические правила: `content/work.json`. Изображения: `assets/work/sawmill/{season}.png`. Правила: `work-rules.js`. Офлайн-каталог сгенерирован в `content/offline-content.js`.

**Ограничения первого отрезка:** автор ещё не описал ветку при похоти 25+, переход дня, восполнение энергии, стартовый кошелёк. Поэтому в этом отрезке подсчитываются заработанные монеты, без утверждения стартового количества. Прогресс рабочего дня хранится только в текущем запуске (прохождение пока нельзя вручную сохранить); новый запуск, как ранее согласовано, открывает заставку. Остальные сезонные иллюстрации привязаны, но смены сезона не происходят без согласованного механизма перехода дня.

Проверки разработчика: `npm test` (на Windows для игры Node.js не требуется). Краткие утверждённые решения и ограничения — `SUSLIK2_STATE.md`.

## Менеджер медиа (Windows)

Дважды щёлкните **`MEDIA MANAGER.cmd`** в установленной папке `suslik-2` (если ставили через установщик — в `%LOCALAPPDATA%\SUSLIK2`). Выберите событие, нажмите «Добавить», при необходимости измените порядок кнопками «Выше/Ниже», затем **«Опубликовать в GitHub»**. После успешной публикации обновите установленную игру. Поддерживаемые форматы: PNG, JPG/JPEG, WebP, GIF, MP4. Музыка не импортируется. Предпросмотра изображений и видео в программе нет.

Сейчас напрямую подключены слоты: «Дальний лес — разрешение гоблина» (до пяти) и «Лесопилка — событие Похоти» (до двадцати). **«Ферма зомби — ночное обучение»** — подготовленное место для будущей авторской сцены: файлы можно положить заранее, но в игре они появятся только после реализации самой сцены. Количество не обязано быть максимальным. Список событий задаётся в `content/media-manager-slots.json`, новые слоты добавляет разработчик по указаниям автора.

Локальные резервные копии файлов размещаются на компьютере в `assets/user-media/manager/`, их настройки — в `content/media-manager-state.json` и `content/media-manager.local.js`. При штатном обновлении эти локальные файлы не перезаписываются. После нажатия **«Опубликовать в GitHub»** изображения и видео становятся частью канонической ветки игры, а их опубликованные пути записываются в `content/media-manager.published.js`.


### Публикация медиа в GitHub (основная кнопка)

В `MEDIA MANAGER.cmd` нажмите **«Опубликовать в GitHub»**. Менеджер загружает выбранные изображения/видео напрямую в проект **`Plegyer/Text`, каноническая ветка `suslik-2/portable-canonical-20261015`** и одним коммитом обновляет `content/media-manager.published.js`. При успехе показывается ссылка на коммит. Изменяется только выбранное событие; остальные опубликованные пути сохраняются. Уже установленную локальную игру нужно обновить, чтобы получить опубликованные файлы. Загрузка медиа для будущей фермерской сцены не создаёт саму сцену.

Для первой публикации нужен доступ GitHub: если установлен и авторизован `gh` (GitHub CLI), он используется автоматически. Иначе окно предложит создать **fine-grained personal access token** для `Plegyer/Text` с правом **Contents: Read and write** на <https://github.com/settings/personal-access-tokens/new>. Вставьте его в окно программы. Токен по желанию сохраняется защищённым способом Windows (DPAPI) в `%LOCALAPPDATA%\SUSLIK2\media-manager-github.token`, но никогда не публикуется в GitHub и не добавляется в игру. Есть кнопка смены доступа.

Поддерживаются PNG, JPG/JPEG, WebP, GIF, MP4; MP3 отсутствует. Ограничение отдельного файла 95 МБ (лимит GitHub — 100 МБ). Файлы после загрузки будут доступны всем, у кого есть доступ к репозиторию. Программа не показывает и не анализирует картинки, только копирует данные и устанавливает ссылки на слоты.


### Готовые сцены, которые можно заполнить сразу

Кроме дальнего леса и лесопилки, менеджер теперь предлагает: **«Гоблин — поражение»** (до 4 вариантов), **«Огр — плен»** (1), **«Концовка „Бригадирша“»** (1), **«Ночная тренировка с гномами»** (1). Это уже существующие игровые сцены: загрузив медиа через «Опубликовать в GitHub», автор сразу подключит изображения/видео к соответствующим местам; правила, тексты и развязки не меняются. Варианты поражения от гоблина выбираются прежней системой случайным образом из 4 мест, поэтому для полного покрытия следует заполнить все 4; незаполненные варианты останутся без медиа. **«Ферма зомби — ночное обучение»** пока только место для загрузки файлов: сюжет и игровой экран ещё не подготовлены.
