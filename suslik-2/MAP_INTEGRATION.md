# SUSLIK 2 — художественная интерактивная карта

Изолированный экран карты: `npm start`, затем `http://127.0.0.1:4173/map.html`. Вход `index.html`, создание персонажа и сохранения остаются частью исходного проекта и не редактировались.

Используется `map.html`, `map.css`, `map.mjs`, `map-locations.json`. Координаты в `viewBox 1672 × 941`. В `assets/map/` находятся один реконструированный фон WebP и **13 PNG с прозрачностью**. PNG и фон получены из единой композиции, не из геометрических заглушек. Система ID не изменена.

На старте видны только `sawmill`, `satyr_bar`, `undead_farm`, `school`. Переключатель предпросмотра показывает все художественные объекты, но закрытые локации не кликабельны и не получают клавиатурный фокус. Демонстрационные диалоги кликабельных зданий сохранены. API `window.SUSLIK2_MAP_TEST` существует для тестов и не сохраняет открытия или бонусы. Фон, PNG и клики находятся внутри одного SVG и масштабируются вместе.

Изображения разделены ручными полигонами с мягкими границами. Пустые участки фона восстановлены *patch-based* ретушью с использованием участков исходной местности. Возможны следы текстурного переноса и повторяющиеся кусты в местах удалённых построек; эта ретушь не заменяет отдельную художественную генерацию/ручную отрисовку фона. Показаны `docs/startup-4.jpg` и `docs/recomposed-all.jpg`.

Проверять через `npm test`, а также браузер с реально загруженными 14 изображениями, переключением старт/предпросмотр, кликами и адаптивным размером. Профессии не открываются автоматически, условия открытия не придуманы, переход из вступления на карту не добавлен.

**GitHub:** комплект из 14 игровых файлов опубликован в ветке `suslik-2/intro-v1` вместе с кодом и манифестом. В ветке остаётся независимый экран `/map.html`; `main` и старый проект не изменяются. Качество восстановленных участков фона требует финальной художественной проверки.
