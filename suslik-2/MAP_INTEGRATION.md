# SUSLIK 2 — автономный тест карты

Открыть при запуске `npm start`: **http://127.0.0.1:4173/map.html**. Главная игра (`/`, `/?restart=1`) не изменена, переход из вступления на карту НЕ добавлен.

Карта отдельно читает `map-locations.json`. 13 постоянных ID и координат в общей системе 1672×941. На старте доступны четыре здания. В предпросмотре видны все здания, для которых указан реальный PNG: после добавления недостающих девяти PNG их будет 13. Сейчас девять локаций ещё имеют `image: null`; для них не рисуются искусственные заглушки. Предпросмотр не открывает профессии и не меняет сохранения.

Изображения должны лежать в `assets/map/map-background.webp` и `assets/map/buildings/{sawmill,satyr_bar,undead_farm,school}.png`. Это извлечённые прозрачные слои и восстановленный фон из утверждённого арта; возможны артефакты ретуши. PNG/WebP не заменяются в коде геометрическими заглушками.

Изображения рисуются отдельным слоем под SVG-областями нажатия в общих координатах. Закрытые здания видимы только в предпросмотре, но не кликабельны и не фокусируются. Клики по четырём доступным зданиям вызывают только демонстрационное окно — игровых экранов локаций пока нет. API `window.SUSLIK2_MAP_TEST` предоставляет позиции и демонстрационные callbacks; НЕ сохраняет открытий, не читает сохранения и не тратит энергию. Условий открытия профессий в текущем `content/scenes.json` нет; они не выдуманы.

Важно: в GitHub-ветке до этой интеграции не было авторских бинарных `assets/splash-title.png` и `assets/character-selection.png` (это зафиксировано в `SUSLIK2_STATE.md`). Эти изображения не менялись и не заменялись заглушками; для старого вступления нужны оригиналы из предыдущего архива.

Тесты: `npm test`.
Обновление предпросмотра: `getVisibleLocationIds()` возвращает фактически отображаемые изображения; `getInteractiveLocationIds()` — только активные кнопки. Проверено поведение в Chromium с тестовыми ресурсами для вариантов 4/13 PNG (видимость, переходы, фокус), но не окончательные изображения, их визуальные наложения или ретушь. Комплект 14 графических файлов пока не готов.
