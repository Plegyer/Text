# SUSLIK 2 — единая проверочная копия для продолжения разработки, 15.10.2026

**Основа:** подлинный архив `SUSLIK2-Windows-TEST-2026-10-15.zip` из авторской проверки. Сохранены оригинальные изображения и музыка из этого архива, а также скопирован новый авторский кадр сна `изображение(20261015-085057).png` в `assets/night/room.png`.

**Запуск для Windows:** распаковать ZIP целиком, открыть `suslik-2/PLAY SUSLIK 2.cmd`. Node.js не требуется, есть portable launcher. Сохранения браузера локальные (`suslik2.save.v1`) и не входят в ZIP.

**Подтверждённое:** команда `npm test` на Node.js 22.16.0 — 79 из 79 тестов; `node --check offline.js gameplay-system.js gameplay-ui.js` — без синтаксических ошибок. В Chromium удалось сделать **ограниченную интерактивную проверку** при загрузке JS напрямую в документ `about:blank`: карта → вход на лесопилку (3/3) → первая смена → диалог гнома → карта → инвентарь → бесплатная ночь на улице → пробуждение → игровое меню; JavaScript ошибок не было. При этом прямая навигация Chromium по `file:` и внешним URL блокируется `ERR_BLOCKED_BY_ADMINISTRATOR`. **Настоящий Windows file:// запуск, стили и воспроизведение музыки не проверены**; нельзя заявлять о релизной готовности.

**Исправления после пользовательской проверки 15.10.2026:**
1. Музыка меню включена для карты и работы на лесопилке (тот же cue `menu`); сохранена ночная и боевая музыка.
2. Сумма «Заработано всего» убрана с результата лесопилки.
3. Работа на сатира выбирает случайную характеристику строго **выше 1**, кроме Похоти; на результате показывает «−1 <характеристика>». Если подходящих характеристик нет — улица.
4. Первое событие с гномом срабатывает **после первой** оплаченной смены (имя флага `shift15` сохранено для старых сохранений); второй разговор по-прежнему требует **не менее 15 смен и Силу/Выносливость ≥15**.
5. К обычному меню сна добавлена бесплатная «Спать на улице».
6. Вход в лесопилку с карты теперь открывает **выбор действий**, а не автоматически тратит энергию. Доступность дальнего леса и других кнопок определяется теми же флагами.
7. Журнал боя ограничен ~3 строками со скроллом, бой под высоту окна; полный экран включается через карту и игровое меню.
8. На карте добавлен Инвентарь: сломанные копья и голова огра.
9. Меню концовок отображает фразу «Вы хотите вырваться из этого порочного круга?».
10. Похоть при зимней смене читается из `run.lust`; не блокирует работу.
11. На карте показаны день, сезон, год, энергия, золото и Похоть.
12. Логи боя называют противника правильно («Огр» вместо «Гоблин»). На карте есть меню «Сохранить» (отдельный ручной слот `suslik2.manual.save.v1`), «Загрузить», «Настройки», «Выход из игры» и «Полный экран».
13. Подключённая «Старт+» начинает следующий заход **с карты**; в прологе кнопка «Разрешить» единоразово даёт +5 Похоти.
14. Восстановлен исходный текст концовки «Трудяга» из `suslik-2/content/creation.json` в ветке `suslik-2/ending-hard-worker-ngplus` GitHub.
15. Авторское новое изображение сна на месте.
16. Встречи с гоблинами в дальнем лесу повышены с 50% до **60%**.

**Важно:** огр пока использует прежние базовые 280 HP и 200 урона, тяжёлая атака промахивается с вероятностью 40% плюс уклонение; пожелание автора сделать бой тяжелее **ещё требует точной балансировки**. Мы не стали менять статистику врага наугад. Для нового чата это открытая задача.

**Остаточные задачи и ограничения:**
- Бар сатиров и ферма нежити по-прежнему не реализованы как полноценные рабочие локации.
- Не все пользовательские GIF/видео концовок подключены; `MEDIA.GAMEPLAY.SCENE` — не ошибка ядра, а незаполненный внешний слот. Меню концовок временно использует существующий фон карты; финальную картинку автор подставит самостоятельно.
- Последние исправления документированы здесь и в архиве, но **исходники этой восстановленной сборки ещё НЕ опубликованы полностью в GitHub**. При переносе в GitHub не смешивать с исходниками старого `main`.
- Механика Похоти утверждена общей для всех работ; только лесопилка пока имеет готовую оплачиваемую реализацию.
- Текущая версия сохраняет переходы, сюжеты и концовки лесопилки, а также 13 оригинальных зданий карты. Не переписывать всё с нуля.
