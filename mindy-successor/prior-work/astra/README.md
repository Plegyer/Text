# Сохранённая работа Astra / Codex

Этот каталог дополняет материалы SOL. Он не заменяет корневую спецификацию successor и не выдаёт старый прототип за готовую игру.

## Стабильный снимок

`prototype-m3.2/` содержит 101 отслеживаемый текстовый файл локального git-коммита `37bc663` (полный SHA в LOCAL_CHECKPOINT.json). Это самостоятельный исходный проект TypeScript/HTML/CSS/Electron: ядро, схемы, контент, UI, редактор подмен, Electron storage, тесты, сборка, lockfile, собственные SVG-заглушки и исторические задания.

Реализованный цикл: создание героини (базовые статы 1, распределение 10 очков), вступление, город, работа, отдельные школьные действия, ручной выбор ночлега, события с условиями и эффектами, простые окончания и наследие. Центр интерфейса — окно медиа; видны дата, монеты и энергия. Сцена/вариант и состояние сохраняются. Три стартовые работы старого прототипа: таверна, лесорубы, охотники. Это историческая конфигурация, не попытка заменить предложенные SOL новые профессии.

Полных JRPG-карт, боёв, палаточного режима и ночных партнёрских линий нет. Дипломы, ранние лавочные показатели и баланс статов относятся к прежним итерациям, которые пользователь счёл недостаточно близкими по системной глубине. Изображения — временные собственные заглушки.

В прошлой сессии для M3.2 фиксировались 43 пройденных теста; это исторический результат, не новый запуск 25 сентября. При передаче проверены байты снимка, JSON-файлы и состав публикации. Windows-установщик в этой передаче не собирался.

Для самостоятельного запуска из prototype-m3.2 при наличии Node >=22.18: `npm ci`, затем `npm run check`, затем `npm start` (Electron). Это команды существующего package.json, не утверждение, что зависимости уже установлены у читателя. Для веб-просмотра после build есть `npm run preview`. Репозиторий намеренно не содержит node_modules, dist, сохранений или внешних пользовательских ресурсов.

## Остановленный M3.3

`wip-m3.3/changes.patch` — изменения отслеживаемых файлов относительно M3.2. `wip-m3.3/untracked/` — новые файлы, которые нужно добавить при отдельном восстановлении WIP. Патч сам по себе этих файлов не создаёт.

В незавершённой работе: START-GAME.cmd, изменения локального сервера, сезонные постановки/медиа лесорубов, вывод карьерного прогресса и замена чрезмерного бонуса +1 энергии за 24 смены на стартовую силу. Есть изменения схемы сохранения/миграции. Пользователь затем остановил наращивание прототипа в пользу изучения оригинала. Не считать M3.3 принятым релизом и не применять автоматически поверх новой архитектуры.
