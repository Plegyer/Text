# Правила продолжения проекта

Читайте README.md, docs/STATUS.md, docs/ARCHITECTURE.md и назначенное задание.
Не создавайте новый проект поверх этого. Сохраняйте публичные контракты и ID.
После каждого завершённого шага: npm run check, обновление STATUS, небольшой git commit.
Незавершённые изменения оставляйте с описанием в STATUS, не удаляйте рабочие версии.
Не меняйте сохранения без версии и явной миграции. Не используйте eval или JS в контенте.
DeepSeek/Cline изменяет только файлы из allowlist задания. Новые зависимости и изменения
ядра требуют отдельного задания. Отклонение от контракта оформляется запросом, не обходом.
Тон: лёгкая взрослая фэнтезийная комедия. Все романтические NPC 21+. Сближение добровольно.
Пока используем только неоткровенные тексты и медиа-заглушки.
Не выдавайте заглушки и ещё не запущенные проверки за готовые системы.
