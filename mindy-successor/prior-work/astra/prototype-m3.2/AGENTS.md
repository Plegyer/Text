# Правила продолжения проекта

Первым источником координации читайте:
- `mindy-successor/docs/tasks/PROJECT_WORK_ENTRYPOINT.md`
- назначенное `CURRENT_CHAT*_TASK_POINTER.md`
- `ACTIVE_TEAM_OWNERSHIP_MATRIX.md`

Не используйте устаревшие статусные документы как источник текущего состояния. Исторические документы могут использоваться только для контекста и сравнения.

Не создавайте новый проект поверх этого. Сохраняйте публичные контракты и ID.
После каждого завершённого шага выполняйте необходимые проверки проекта и делайте небольшой git commit с фактическим изменением.
Незавершённые изменения оставляйте с описанием в актуальных task/handoff файлах, не удаляйте рабочие версии.
Не меняйте сохранения без версии и явной миграции. Не используйте eval или JS в контенте.
DeepSeek/Cline изменяет только файлы из allowlist задания. Новые зависимости и изменения ядра требуют отдельного задания. Отклонение от контракта оформляется запросом, не обходом.

Тон: лёгкая взрослая фэнтезийная комедия. Все романтические NPC 21+. Сближение добровольно.
Пока используем только неоткровенные тексты и медиа-заглушки.
Не выдавайте заглушки и ещё не запущенные проверки за готовые системы.
