# Принятые решения

## 2026-09-22 — M1

- Сохраняем TypeScript + HTML/CSS + Electron, без UI-фреймворка на первом этапе.
- Zod — единый контракт TypeScript/runtime/JSON Schema. Зависимости фиксированы lockfile.
- Полный календарь есть сразу; стартовый контент ограничен одной профессией.
- 10 характеристик 0–100, 3 действия в день. Ночь обрабатывается автоматически.
- Событие вызывается после действия; его выбор не тратит второй ход.
- Повторяемые постановки выбираются детерминированно по истории, без RNG в M1.
- Один файл SaveEnvelope содержит Run и Meta для целостного присуждения наследия.
- Версия сохранения 1. Единственная текущая версия; будущие версии отклоняются,
  миграция появится вместе с первым изменением контракта сохранения.
- Сохранение не содержит текста и медиа, только ID и состояние. Нельзя удалять
  опубликованные ID без миграции и проверки загруженных сцен.
- UI не даёт начать новую жизнь посреди активной: принять судьбу или окончить срок.
- Критическая логика сначала проверяется интеграционными маршрутами.
- Локальная Git-история + переносимый архив + инструкция продолжения защищают
  от лимитов сессии. Удалённый Git ещё не подключён; не утверждать, что он есть.
- Графический редактор пока заменён инспектором только для чтения. Не называть
  его готовым редактором. Полные отношения, бедность, экипировка и мини-игры впереди.
- Выпуск Windows требует отдельного запуска и проверки на Windows.

## Не менять без отдельного решения

Календарь, разделение Run/Meta, семантику транзакции, стоимость действия,
награды основных судеб, schemaVersion/contentVersion и namespace принятых пакетов.

## 2026-09-23 — M3, по замечаниям пользователя
- Центральное медиа-окно и отдельные игровые меню заменяют dashboard.
- Начало статов 1 + 10 очков; отдельный lust. Названия первых десяти меняются, ключи сохраняются.
- Энергия стала единственным бюджетом занятий. Сон явный, аренда ночная и растёт по годам. Это заменяет правила M1 об автоматической ночи.
- Schema 3 добавляет создание героини, RNG и lastAction. Последний содержит снимок текста результата, чтобы восстановить экран; это явное исключение из старого правила «в save только ID».
- Перезапуск доступен с подтверждением, наследие сохраняется. Полный сброс профиля не совмещать с новой жизнью.
- M3 содержит визуальную проверку Electron renderer; Windows требует собственной проверки.
