# Как заменить текст или изображение — M2

Запустите игру и откройте «Тексты и изображения». Выберите фрагмент: название события, текст постановки, подпись выбора, результат выбора, описание действия или эпилог. Отредактируйте текст; «Вставить абзац» вставляет блок в текущую позицию курсора. «Сохранить текст» применяет замену. Это редактор представления, не редактор квестовой логики.

У новой сцены и каждой сезонной постановки свой ID медиа, даже если временный эскиз одинаков. Выберите слот медиа, загрузите PNG/JPEG/WebP/GIF до 2 МБ или укажите путь assets/my-file.webp. Для видео используйте assets/my-video.mp4 или .webm. Укажите описание, проверьте предпросмотр и сохраните. Большие файлы кладите в assets/ исходного проекта и выполняйте npm run build. В готовом браузерном dist можно добавить файл в dist/assets/. Упакованный Electron требует пересборки для новых локальных файлов, но импорт небольших изображений работает через редактор.

Замены живут отдельно от игровой жизни в локальных данных приложения. Экспортируйте presentation.json: это переносимый пакет замен, НЕ сохранение персонажа. Импорт пакета заменяет текущий набор замен целиком. Для включения в следующую сборку положите экспорт в content/presentation.json, затем npm run check. Исходные тексты событий останутся в content/packs. Исторические записи дневника не меняются задним числом; открытая сцена отображает текущий текст по прежнему ID.

Условия, эффекты, ID, стаж и награды через этот редактор менять нельзя. Неизвестные поля, неизвестные ID и опасные адреса отклоняются. Ошибка сохранения замен не меняет жизнь. При переполнении локального хранилища уменьшите встроенные картинки или используйте assets/. JPEG разрешён в заменах; базовый каталог M1 пока ограничен SVG/PNG/WebP/GIF/видео.

Пример ключа: event/gopher.arrival/variant/default. Для изображений: gopher.arrival.default, gopher.tavern-routine.spring. Вставка нового сюжетного выбора или события — отдельный контентный пакет, а не вставка произвольного программного кода.

## M3: сцена работы и её замена
Ключи action/lumber/scene/spring (также summer/autumn/winter) и аналогичные для tavern/hunt/guard меняют текст обычной смены. Медиа stage.lumber.spring и другие сезонные ID меняют рабочую иллюстрацию. Слоты stage.goblin, stage.sparring, stage.flirt относятся к встрече и двум результатам. Менять можно GIF, изображение или локальное MP4/WebM; условия и награды от этого не меняются. Пока разные сезоны используют общие временные эскизы.
