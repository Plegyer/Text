# DS-007 — отчёт

## Что готово
Создан presentation-черновик `content/presentation-drafts/DS-007.json` в формате
`{version:1,texts:{...},media:{}}` с ровно восемью ключами из контракта
`docs/contracts/DS-007.json`:

- `action/lumber/scene/spring|summer|autumn|winter`
- `action/hunt/scene/spring|summer|autumn|winter`

Каждая постановка — 120–450 знаков, лёгкая бытовая комедия, повторяемая рабочая сцена
без новых сюжетных фактов, квестов и наград. У лесорубов фигурируют только героиня и
Бронн, у охотников — героиня и Рен. Ни одна сцена не выдаёт неизбежную победу или
неудачу за результат смены. Флаги и характеристики не читаются и не изменяются; это
только текст обычной смены. `media` — пустой объект.

Добавлен тест `tests/ds-work-scenes.test.ts` (три проверки):
1. ровно восемь ключей, пустой `media`, длины 120–450, нет повторов;
2. `applyPresentation` подставляет все восемь текстов и не меняет условия/стоимость/
   награды/сезонные эффекты/заработок/медиа исходного каталога;
3. неизвестный ключ отклоняется.

## Результаты команд
- `npm run check` — успех: typecheck, validate (3 packs, 18 events, 25 actions,
  6 endings), build, 35/35 тестов.
- `node --experimental-strip-types --test tests/ds-work-scenes.test.ts` — 3/3.
- `npm run check:package -- DS-007` — не выполнен до конца: в этой среде не установлен
  `git`, а скрипт `scripts/check-package.ts` на шаге 10 вызывает `git diff`/`git ls-files`
  для проверки границ allowlist и падает с `spawnSync git ENOENT`. Тест проверяет форму overlay, но не границы изменённых файлов; проверка allowlist остаётся за интегратором.

   молчание Рена.

## Ограничения
- Результат не подключён автоматически (как требует задание); объединение с
  `content/presentation.json` выполняет интегратор.
- Без git нельзя прогнать `check:package` и создать commit/checkpoint в этой среде.
- Медиа-заглушки не загружались; слоты `stage.lumber.*`/`stage.hunt.*` уже существуют,
  пользователь подставит GIF отдельно.

черновик с существующими пользовательскими заменами и создать новую контрольную точку.
