Начать с DS-004-lumber.md. Затем DS-005-seasons.md и DS-006-marek.md. Вставьте текст задания в Cline, открыв существующий проект. DeepSeek не запускается из этой среды: задачи передаются пользователем. Старые DS-001–003 — архив M1, не выполнять одновременно с текущими без отдельной проверки. DS-000 Windows-check остаётся актуальным для настольного запуска.

На чистом дереве: git worktree add ../portal-ds004 -b content/ds004 m3-stage. Для других задач используйте отдельные ветки и каталоги от того же тега. Общие файлы и STATUS меняет только интегратор.

Прочитать AGENTS.md, STATUS, WORLD, назначенное задание и docs/contracts/DS-XXX.json. Менять только file/test/report контракта. Нехватка схемы — повод сообщить о блокере, а не переписывать ядро. Разрешённые флаги уже зарегистрированы интегратором.

Приёмка: npm run check:package -- DS-004 (или свой номер), затем npm run check. Проверка границ включает tracked и untracked файлы, права флагов, счётчики, частоту, медиа, метрики и бюджет эффектов. Она не доказывает качество текста, правильность персонажей и достижимость всех путей: это проверяют интегратор и сценарные тесты.

Передать коммиты или архив file/test/report. Интегратор читает diff, проверяет добровольность отношений и отказ, играет маршрут, переносит ОДИН пакет, повторяет проверки и создаёт checkpoint. При лимите сохранить незавершённое и записать последний шаг в личный отчёт; не сбрасывать чужие изменения и не создавать новый проект.
