# DS-001 — первые поручения алхимической лавки

Создай пакет ds-alchemy по docs/contracts/DS-001.json и content/pack.schema.json.
Разрешены ровно content/packs/ds-alchemy.json, tests/ds-alchemy.test.ts,
docs/tasks/DS-001-report.md. Остальные файлы не менять.

Четыре события: три однократные связанные сцены и один повторяемый набор с шестью
постановками. Последовательность: проверить этикетки -> обнаружить комичную
путаницу -> объяснить исправление Орвину. Каждая веха устанавливает следующий
флаг ds.alchemy.first/second/done. Уникальные сцены только после предыдущей;
первой требуется alchemy.intro. Это дополнительный сюжет, не основной заказ.

Орвин — взрослый спокойный алхимик с сухим юмором; Бран — взрослый курьер 27 лет,
добродушный и разговорчивый. Не устанавливать новые факты их биографий.
Никакой драмы, скрытого заговора или откровенных сцен.

Повторяемый набор: maxShows 4, cooldownDays 14, variantCooldownDays 56.
Одна постановка универсальная, остальные могут проверять разрешённые навыки.
Однократные: maxShows 1. priority всех событий 5. Триггеры work/brew.
Метрики intellect здесь называются intelligence — использовать только ID контракта.
Не менять деньги, предметы, работу, уроки, наследие или основной заказ.

Варианты по 50–100 русских слов, выборы по 1–2 предложения. По 2–3 выбора,
как минимум один без условий и затрат. Медиа: только base.workshop, одна ссылка
на постановку; дополнительные визуальные идеи записать в отчёт, не новые файлы.

Тесты: сцены проходят по порядку из достижимого состояния, флаг каждого шага
выдаётся один раз, повтор выдерживает интервалы, доступен выход при низких навыках.
Используй tests/helpers.ts и dispatch; не подменяй ядро моками.

Готовность: npm run check:package -- DS-001 и npm run check. Создай commit
только с разрешёнными файлами. Отчёт: маршрут, тесты, ограничения, новые медиа-идеи.
