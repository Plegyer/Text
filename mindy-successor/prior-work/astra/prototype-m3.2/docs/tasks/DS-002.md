# DS-002 — зимние бытовые микро-события

Создай пакет ds-winter по docs/contracts/DS-002.json и content/pack.schema.json.
Allowlist: content/packs/ds-winter.json, tests/ds-winter.test.ts,
docs/tasks/DS-002-report.md. Не менять ядро, базовый пакет, схему и зависимости.

Восемь событий, в каждом три короткие постановки по 25–55 русских слов.
Темы: упрямая метла, очередь за горячим хлебом, потерянная варежка, скользкая
табличка, снег на вывеске, дрова неправильной формы, обледеневшая посылка,
соседский спор об идеальном чае. Не повторять текст base.winter.

Только безымянные взрослые горожане, без новых постоянных NPC. Зима обязательна
как прямое condition season=winter у КАЖДОГО события. Флаги не читать и не менять.
Триггеры forage/oddjob/rest; priority 4. maxShows 4, cooldownDays не менее 28,
variantCooldownDays не менее 56. Медиа только base.town.

У каждой сцены два выбора, один нейтральный без затрат. Эффекты только из контракта,
не больше 2 пунктов в одной метрике за выбор. Никаких денег, предметов, новых
болезней, выселений, романтических обязательств или штрафов за отказ от флирта.
Варианты могут учитывать жильё; обязательна универсальная запасная постановка.

Тесты: весной/летом/осенью ни одно событие не проходит условия; зимой доступны;
все три типа жилья имеют хотя бы одну подходящую постановку; cooldown сохраняется
после save/load; действие rest остаётся безопасным выходом при нулевой энергии.

Готовность: npm run check:package -- DS-002 и npm run check, отчёт и маленький commit.
