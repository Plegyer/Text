# DS-000 — проверка первого запуска на Windows

Это проверка, а не задача изменения архитектуры. Разрешён только файл
 docs/tasks/DS-000-report.md. При ошибке записать команду, сообщение и шаг; код
не переписывать, передать отчёт Astra. Временные сборки — только в release/.

1. npm ci, npm run check. Ожидается 24 базовых теста (больше после приёма пакетов).
2. npm start. Убедиться, что календарь, действия и изображения видны.
3. Смена -> представиться -> закрыть окно -> открыть. Прогресс должен остаться.
4. Достичь судьбы артели: 5 смен (отвечать на сцены), отдых, две щадящие варки,
   сдача общего заказа. Не тратить исходные травы/микстуры на другое.
5. В разделе Судьбы принять судьбу; в дневнике появился эпилог.
6. Начать следующую жизнь: организация 25, наследие артели, старые смены обнулены.
7. Экспортировать JSON. Сделать действие, импортировать старый файл. Открытия
   постоянного профиля должны сохраниться. Ошибочный JSON отклоняется.
8. npm run dist:win. Установить приложение, проверить запуск и автосохранение.
9. Записать версии Windows/Node, команды, результат каждого пункта. Не называть
   тест пройденным, если проверена только сборка без открытия установленной игры.

Повреждение основного сохранения можно проверять только на копии тестового
профиля, предварительно экспортировав данные. Никогда не удалять пользовательские сейвы.
