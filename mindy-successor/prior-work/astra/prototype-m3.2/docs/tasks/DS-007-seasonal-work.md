# DS-007 — восемь сезонных рабочих постановок

База m3-stage. Прочитать AGENTS, STATUS, WORLD, CONTENT-EDITING и контракт docs/contracts/DS-007.json. Менять только три файла контракта; ядро, UI, исходные пакеты, зависимости, сохранения и существующий presentation.json запрещены.

Создать content/presentation-drafts/DS-007.json в формате {version:1,texts:{...},media:{}}. Ровно восемь ключей из textKeys контракта: lumber/hunt × spring/summer/autumn/winter. По 120–450 знаков, лёгкая бытовая комедия, без новых сюжетных фактов, квестов и наград. Для лесорубов разрешены героиня и Бронн, для охоты героиня и Рен. Не добавлять других именованных NPC. Не выдавать неизбежную неудачу или победу за результат каждой смены. Сцены должны подходить повторяемой работе.

Флаги и характеристики не читать и не изменять. Это только текст обычной смены. Медиа оставить пустым объектом: уже есть восемь сезонных слотов stage.lumber.* и stage.hunt.*; в отчёте описать по одному неоткровенному кадру для каждого, без загрузки чужих ассетов. Пользователь подставит GIF отдельно.

Тест загружает полный каталог и применяет overlay через applyPresentation. Проверить все восемь текстов, неизменность условий/стоимости/наград и исходного каталога; неизвестный ключ должен отклоняться. Использовать существующие функции, не создавать другой движок. Выполнить npm run check:package -- DS-007 и npm run check.

Результат автоматически не подключать. Отчёт: что готово, результаты команд, восемь кадров, ограничения, следующий шаг при прерывании. Приёмка интегратором: тон, повторяемость, точные ключи, отсутствие изменений механики; только затем объединение с presentation.json и новая контрольная точка.
