# Очередь после M1

## M1.1 — проверка настольного приложения (Astra/локальная машина)
Запустить npm ci / npm run check / npm start на Windows; пройти одну судьбу,
перезапустить приложение, проверить NG+, экспорт, импорт и резервную копию.
Собрать npm run dist:win, установить в другой каталог, убедиться в сохранности save.
Не менять дизайн до устранения ошибок запуска. Не выпускать установщик без проверки.

## M2 — инструменты автора (Astra)
Редактор формы события, live-валидация, предпросмотр на сохранении, импорт/экспорт
пакета, объяснение условий. Затем граф зависимостей и безопасное сохранение правок.
Использовать core/content и schema, не создавать вторую систему условий.

## Контент параллельно (DeepSeek/Cline)
DS-001 — лавка; DS-002 — зимние микрособытия; DS-003 — Бран.
Все совместимы с M1, отдельные файлы и ветки. Приёмка после каждого пакета.

## M3 — расширение life-sim (Astra)
6 стадий жилья/бедности, сроки аренды и отсрочки, отдельные отношения NPC,
учебные курсы/экзамены, сезонные профессии, способности оборудования,
выбор двух стартовых наследий. Каждое изменение state — отдельная миграция.

## M4 — контент и системное тестирование
Расширять до утверждённого бюджета 358 определений и 24 судеб.
Добавить экспедиции и рынок, затем проверку достижимости с тремя исходами
(маршрут найден / невозможность доказана / не установлено), анализ экономики,
частоты событий и содержательные симуляции четырёхлетних жизней.

При достижении лимита: завершить маленькую контрольную точку, отметить текущий
шаг, последний зелёный тест и следующую команду в STATUS. Не начинать переписывание.
