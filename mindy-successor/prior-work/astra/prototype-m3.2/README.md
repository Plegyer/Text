# По ту сторону люка / Portal Life — M3.2

Прототип фантазийной life-sim RPG на TypeScript + HTML/CSS + Electron. В центре теперь игровая сцена, сверху дата, монеты и энергия; занятия и характеристики открываются отдельными меню.

## Что попробовать
Создайте героиню: все характеристики начинаются с 1, распределите 10 очков. Пройдите вступление. Откройте работу: таверна, лесорубы, охотники; стража требует подготовки. После смены можно работать ещё. Каждая смена стоит 1 энергию; исходные запасы — 3. Сон выбирается вручную и требует оплаты, помощи хозяину или ночёвки на улице.
У лесорубов после знакомства и стажа возможна встреча, заменяющая рабочую сцену. Есть учебный поединок и необязательный флирт при Желании 6. Желание повышается в салонном классе. Встреча вероятностная, с двухдневным cooldown: она не гарантирована в каждую смену. Изображения пока временные, пила анимирована. Пользовательские GIF/видео подключаются через меню редактора.

## Запуск
В каталоге проекта: npm ci, затем npm run check и npm start. Нужен Node.js 22.18+.
Браузер: npm run build, npm run preview; http://127.0.0.1:4173.
В архиве уже есть dist: node scripts/serve.mjs запускает браузерную сборку без установки зависимостей.
Windows-установщик: npm run dist:win. Сам установщик в этой среде не проверен. Закройте прежнюю M2 и запускайте из распакованного каталога M3.

## Сохранения и восстановление
M1/M2 мигрируют в schema 3 с сохранением прогресса и прежних статов. Чтобы увидеть старт с единицами, выберите перезапуск в меню; это новая жизнь с сохранённым наследием. Сначала экспортируйте текущую жизнь, если хотите вернуться к ней. presentation.json с заменами текста/медиа переносится отдельно.
Не создавайте новый каркас: AGENTS и docs/STATUS.md описывают продолжение. После проверки — commit и npm run checkpoint. Архив содержит исходники, dist и history.bundle. История восстанавливается командой git clone history.bundle ../portal-life-restored. Храните внешнюю копию архива.

## DeepSeek и готовность
Начните с docs/tasks/README.md. Подготовлены DS-004 (лесорубы), DS-005 (сезоны), DS-006 (Марек), DS-007 (сезонные рабочие постановки). Ядро и интеграция остаются центральными.
21 событие / 25 действий / 6 судеб; 43 теста. Настоящий Electron renderer проверен на нескольких размерах экрана. Это ещё не полная игра: JRPG, длинные отношения и большинство профессий впереди. Сюжет — docs/WORLD.md; замены — docs/CONTENT-EDITING.md.

M3.1: DS-007 принят и подключён. Восемь сезонных постановок лесорубов/охотников обновлены; пользовательские замены имеют приоритет по отдельным ключам. Следующая задача DeepSeek — DS-004; её выполнять в отдельной ветке от указанного в контракте m3-stage, затем передать три файла интегратору.

M3.2: SOL-001 интегрирован. Работайте лесорубом: новые этапы появляются на 3-й, 7-й и 12-й сменах, летом и зимой используются отдельные постановки. Обе кнопки продвигают цепочку, награды выдаются один раз. Старая жизнь совместима; начинать заново не обязательно. Предыдущие указания выдать DS-004 относятся к истории — задача завершена.
