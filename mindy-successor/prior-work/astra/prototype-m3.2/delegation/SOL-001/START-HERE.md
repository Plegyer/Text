# Передача SOL в обычном чате
Прикрепите этот архив и напишите: «Выполни SOL-001 по TASK.md. Исходники в project.zip. Сначала создай контентный пакет из принятых A/B, затем сценарные тесты. Не меняй архитектуру. Верни только три разрешённых файла; если запуск недоступен, явно укажи это».

Не прикладывайте историю проекта из чата. Если среда не умеет открывать вложенный ZIP, распакуйте project.zip локально и прикрепите только источники из списка чтения TASK. Если нельзя создавать файлы, допустимы три отдельных блока кода с путями: интегратор соберёт их. Доступность инструментов и лимиты вашей подписки здесь не предполагаются.

Контроль затрат: одна ограниченная задача за сессию. Не обращаться к Astra только ради передачи каждой реплики: возвращайте готовый пакет или конкретный воспроизводимый блокер. Приёмка не обязана выполняться самой дорогой моделью, если изменение не затрагивает общие правила.
