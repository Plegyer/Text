# Запуск пользователем
Распакуйте архив. Откройте в Cline ТОЛЬКО папку executor как отдельную рабочую папку, вне каталога игры. Не прикладывайте весь проект или старую переписку. Скопируйте этот запрос:

«Выполни DS-004A. Прочитай целиком только AGENTS.md, TASK.md, CONTEXT.md и result.json в текущей папке. Заполни разрешённые строки result.json по заданию, сохраняя файл после каждой сцены. Если строки уже заполнены, продолжи с пустых. Код, тесты, Git, поиск по проекту и отчёт не нужны. После чтения переходи к редактированию. В конце дай только короткий статус».

Верните интегратору один executor/result.json. Не копируйте его в content/packs: это промежуточный формат. Старые DS-004 и его требование трёх постановок на сцену не отправляйте одновременно. Сейчас создаются только три базовые сцены; шесть сезонных альтернатив будут отдельным заданием после приёмки.

При обрыве не начинать заново: оставить файл, открыть чистую сессию в той же папке и повторить запрос. Если даже одна сцена не успевает сохраниться, следующему запуску поручить только scenes[0], затем scenes[1], затем scenes[2], не меняя остальные объекты. Инструментальная ошибка до записи не означает, что файл появился; проверяйте наличие непустых строк.

Размер пакета ограничивает источники проекта, но не системный контекст Cline и не скрытые лимиты провайдера. Исчезновение таймаута не гарантируется. При повторной ошибке сохранять точное сообщение и номер сцены; не расходовать попытки на одинаковый большой запрос.
