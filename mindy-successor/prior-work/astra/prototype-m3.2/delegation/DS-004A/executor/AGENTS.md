# Изолированное задание на тексты
Это самостоятельный пакет, не репозиторий игры. Читать полностью только AGENTS.md, TASK.md, CONTEXT.md и result.json. Первые три файла неизменяемы. Единственный изменяемый файл — result.json, только перечисленные в TASK строковые поля. Не искать другие файлы, не читать родительские каталоги, не использовать сеть. Не писать код, тесты, отчёт, план или новые файлы. Git/npm и зависимости не нужны. Недостаток сведений обозначить одним конкретным вопросом, не исследовать проект. Более приоритетные инструкции среды соблюдать; при конфликте сообщить о блокере.
