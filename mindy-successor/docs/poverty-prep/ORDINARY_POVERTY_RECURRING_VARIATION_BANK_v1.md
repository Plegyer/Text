# Ordinary Poverty Recurring Variation Bank v1

Status: RU+EN presentation-only variation bank for already-shipped repeatable ordinary-poverty event families.

This bank does not create gameplay variants. Each entry is an optional presentation candidate beneath an existing shipped event/variant identity. Conditions, effects, rewards, timing, RNG, cooldowns, maxShows, NightFlow, and save-state identity remain unchanged.

Russian is the source authoring language; English is the full second locale.

## Use rule

For an existing event/variant, presentation may rotate among these prose candidates only after the gameplay event and variant have already been selected. A prose candidate must never change:
- available choices;
- choice effects;
- reward amount;
- next-day modifiers;
- lodging cost;
- event history;
- Secret Debt state.

Candidate IDs below are presentation-only and must not be persisted as gameplay event IDs.

## Editorial guardrails

These variation banks intentionally avoid:
- exact money amounts;
- exact Energy/Grooming values;
- new inventory quantities;
- new season/day requirements;
- new lodging prices;
- new safe exits;
- new rewards;
- new Secret Debt implications.

If a candidate appears to suggest an effect that the selected production choice does not actually have, it must not be used.

## Integration note

These are prose alternatives, not additions to `event.variants[]`. A future presentation layer may use them as text candidates only after the authoritative event/variant/choice state has been selected.
