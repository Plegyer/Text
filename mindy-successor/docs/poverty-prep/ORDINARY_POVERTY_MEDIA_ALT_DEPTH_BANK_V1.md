# Ordinary Poverty Media Alt Depth Bank v1

Status: RU+EN presentation-only alt/caption bank for current ordinary-poverty presentation identities and future real media.

No media file, catalog entry, presentation slot, runtime behavior, RNG, event identity, or gameplay outcome is changed by this document.

Russian is the source authoring language; English is the full second locale.

## Alt/caption rule

**Alt** should identify the visually relevant scene without retelling mechanics or naming a reward/penalty.

**Caption** may add atmosphere, but it must not reveal hidden state, promise a specific effect, or imply Secret Debt.

One gameplay event may eventually use 3–5 media candidates. All candidates remain presentation-only.

## Accessibility guardrails

Alt text should not:
- state exact rewards or penalties;
- describe a choice as correct/incorrect;
- announce future state;
- name Secret Debt when it is not visibly present;
- identify a character or provider not established by the image;
- infer emotions not visually readable.

Captions may be more atmospheric, but must preserve the same gameplay firewall.
