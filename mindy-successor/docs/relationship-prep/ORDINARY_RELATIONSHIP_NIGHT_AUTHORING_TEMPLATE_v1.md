# Ordinary Relationship Night Authoring Template v1

Status: reusable template for voluntary ordinary Night content.

Required fields:
- Night choice ID and owning relationship ID;
- required relationship stage/public conditions;
- Night slot ownership: voluntary choice;
- housing context: none / normal / cheap / street / Product-open;
- explicit next-day modifier: value and reason, including 0;
- RU title/body/choice text;
- EN title/body/choice text;
- semantic presentationId, media ID, static fallback and RU/EN alt;
- exact post-choice reaction trigger, if any;
- Save/reload identity assumptions;
- Product-open markers.

Rules: the interaction does not spend daytime Energy. There is no universal next-day Energy penalty. Housing never changes availability unless an explicit approved condition says so. Locale and media are presentation-only. Trigger IDs, relationship state, RNG and Save identity stay locale-neutral. Forced Secret Debt NightFlow is outside this template.
