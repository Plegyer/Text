# Successor — stat system draft v0

Статус: **DESIGN DRAFT, НЕ ЗАФИКСИРОВАНО**.

Цель — сократить перегруженные/пересекающиеся 11 progression stats оригинала, сохранив достаточно осей для jobs, school, story gates, optional events и будущей large activity.

## 1. Проблема оригинального набора

Simply Mindy использует:
- Strength;
- Durability;
- Prowess;
- Intellect;
- Spirit;
- Charisma;
- Sociability;
- Class;
- Creativity;
- Cleanliness;
- Fuckability.

Morality хранится отдельно.

Система работает, но несколько осей сильно пересекаются:
- Charisma / Sociability / Class;
- Intellect / Creativity;
- Cleanliness ведёт себя как permanent progression stat, хотя тематически часто похоже на volatile condition;
- Prowess имеет очень широкую семантику.

Для successor не нужно сохранять число 11 ради сходства с оригиналом.

## 2. Предлагаемые 9 core stats

### Сила
Грубая физическая мощь.

Использование:
- тяжёлый труд;
- force solutions;
- перенос/рубка/бой, если будущая activity это использует;
- physical career gates.

### Выносливость
Способность переносить нагрузку, боль, долгую работу и тяжёлые условия.

Не путать с дневной Energy:
- Energy = сколько действий сегодня;
- Выносливость = качество персонажа/build stat.

### Ловкость
Точность, координация, быстрые и аккуратные физические действия.

Заменяет значительную часть слишком широкого original Prowess.

### Разум
Знания, обучение, логика, теория, анализ.

Основная характеристика академических/интеллектуальных решений.

### Магия
Мистическая чувствительность, владение сверхъестественным и сопротивление магическим задачам.

Не обязана означать combat spell power; точная роль будущей large activity пока OPEN.

### Смекалка
Импровизация, творчество, практическое решение нестандартных проблем.

Наследует полезную нишу original Creativity, но формулируется шире и лучше подходит fantasy-world jobs/events.

### Обаяние
Личное влияние, привлекательность, убеждение, способность расположить к себе конкретного персонажа.

### Манеры
Социальная компетентность другого типа:
- этикет;
- самообладание;
- умение вести себя в конкретной среде;
- профессиональная подача;
- понимание социальных норм.

Это объединяет наиболее полезные функции original Sociability + Class, не дублируя Обаяние.

### Похоть
Положительный content stat.

Уже зафиксированный принцип:
- высокая Похоть открывает/заменяет дополнительные content variants;
- не уменьшает зарплату;
- может быть requirement/reward/route selector;
- не является corruption meter с автоматическим наказанием.

## 3. Что вынести из core stats

### Ухоженность — volatile condition, а не permanent progression stat

Предлагается НЕ переносить original Cleanliness как обычную характеристику, которую игрок бесконечно качает школой.

Вместо этого возможно отдельное состояние:
`Grooming / Ухоженность`.

Оно может:
- падать после грязной работы/ночёвки/события;
- восстанавливаться жильём, баней, отдыхом;
- временно влиять на social jobs/scenes;
- иметь thresholds.

Это делает его ресурсом ежедневного планирования, а не странной permanent "интеллектоподобной" характеристикой.

Само наличие Grooming ещё не фиксируется; фиксируется только идея не смешивать volatile conditions с permanent build stats.

### Morality / Alignment

Не делать обычным stat-point параметром.

Если новой игре понадобится мораль/репутационный путь:
- хранить choices/tags;
- faction values;
- route flags;
- derived alignment.

Игрок не должен ходить в школу и покупать +4 Morality.

## 4. Mapping от оригинала

| Simply Mindy | Successor draft |
|---|---|
| Strength | Сила |
| Durability | Выносливость |
| Prowess | Ловкость |
| Intellect | Разум |
| Spirit | Магия |
| Creativity | Смекалка |
| Charisma | Обаяние |
| Sociability + Class | Манеры |
| Cleanliness | не core stat; возможная Ухоженность-condition |
| Fuckability | Похоть |
| Morality | route/faction/derived state, если понадобится |

Это не перенос названий один-к-одному, а сохранение разных системных функций.

## 5. Почему 9 лучше 11 для этой игры

### Меньше ложных различий
Игроку не нужно угадывать разницу между тремя почти одинаковыми social stats.

### Проще построить 10 профессий
При 9 stats каждая характеристика может реально участвовать в нескольких jobs, а не существовать ради одного gate.

### Школа становится читаемее
Course packages легче понимать и балансировать.

### Random/reactive events получают хорошие альтернативы
Типовой event может предлагать:
- физический подход;
- умственно-магический подход;
- социальный/необычный подход.

### Похоть остаётся особой осью
Она не растворяется в Обаянии и сохраняет role content router.

## 6. Проверка job matrix перед фиксацией

Набор статов нельзя считать принятым, пока не существует черновой матрицы всех 10 обычных jobs.

Для каждого stat желательно проверить:
- минимум 2 профессии, которые его заметно развивают;
- минимум 1–2 профессии, где он является career gate;
- применение вне работы;
- отсутствие "мёртвого" stat, который нужен ради одной сцены.

Отдельно нужно проверить tradeoff matrix:
каждая работа даёт +2 stats / -1 stat, но один и тот же stat не должен становиться универсальной свалкой отрицательных значений.

## 7. Три стартовые работы пока НЕ получают окончательные deltas

Зафиксированы:
- лесоруб в артели гномов;
- служанка в баре сатиров;
- помощница на ферме у нежити.

На этом этапе намеренно не назначаем им финальные +2/-1.

Сначала нужно придумать остальные 7 обычных профессий и посмотреть всю stat/job матрицу целиком. Иначе первые три решения заранее перекосят систему.

## 8. School implication

При 9 core stats school может иметь:
- простые дешёвые пары;
- дорогие multi-stat courses;
- специальные rule-changing/swap options.

Похоть может присутствовать в отдельных курсах, но школа не обязана повышать её почти каждым уроком, как оригинал.

## 9. Large-activity implication

Поскольку replacement JRPG ещё не выбран, stat set не должен быть спроектирован под combat.

Достаточно, чтобы будущая activity могла использовать общий interface:
- physical checks: Сила / Выносливость / Ловкость;
- cognitive checks: Разум / Смекалка;
- supernatural checks: Магия;
- social checks: Обаяние / Манеры;
- content variants: Похоть.

Это оставляет свободу для expedition, puzzles, tests или другой системы.

2. Job/stat coverage matrix 10 x 9.
3. School coverage.

5. Только после этого зафиксировать stat list и стартовые values.
