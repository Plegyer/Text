# Meta Loadout Model v1

Дата: 2026-09-25.

Статус: **TARGET PRODUCT DRAFT**.

Основание:
- fresh profile hardest;
- Hard Work rewards automatic and cumulative;
- complex endings may unlock strong rule-changing rewards;
- user wants later lives to become easier and more flexible.

## 1. Two layers of meta reward

### Automatic legacy
Always active:
- Hard Work stat/start-money rewards;
- permanent knowledge;
- profession/content unlocks;
- harmless starting contacts;
- Palace progress.

These accumulate forever.

### Strong Legacy Perks
Unlocked by complex endings.

Before a new run player chooses a limited number of active strong perks.

Examples:
- +1 daily Energy;
- rent disabled/reduced;
- daily income;
- stat carry-over;
- advanced School discount;
- extra starting item package;
- special Activity access;
- extra calendar time.

## 2. Slot model

Candidate:
- before Palace: 2 strong Legacy slots;
- after first Palace completion: 3 strong Legacy slots.

This is intentionally more permissive than a single-title system while still preserving build choices.

## 3. Why not make all strong perks automatic

If every rule-break stacks automatically:
- late runs can lose all planning;
- some endings become mandatory optimal choices;
- testing combinations explodes.

Automatic Hard Work rewards already guarantee every ending makes the profile stronger.

Strong-perk slots preserve player choice without erasing meta growth.

## 4. Why later lives still get easier

Even with limited strong slots:
- automatic Hard Work bonuses stack;
- starting money can stack where explicitly automatic;
- knowledge/content unlocks accumulate;
- player gets more strong perk options;
- Palace adds another slot.

So late profile has:
- higher base stats;
- more cash;
- more routes;
- better perk combinations;
- less survival friction.

## 5. Suggested perk strength bands

### Major
Usually consumes 1 slot:
- +1 Energy/day;
- no rent;
- 25% previous-run stat carry-over;
- extra year / +40 days.

### Medium
Can still consume 1 slot if very broad:
- School -25%;
- daily passive income;
- Activity entry discount;
- one advanced item package.

### Minor
Prefer automatic:
- starting contact;
- one ordinary tool;
- one certificate;
- specific route knowledge.

## 6. No hidden perk stacking

Each perk defines:
- stackable? yes/no;
- exclusive group;
- exact timing;
- whether it affects derived Energy/stat caps;
- save/migration ID.

No duplicate hidden bonuses.

## 7. UI

Before starting a run:
- show automatic legacy summary;
- show unlocked strong perks;
- select up to slot count;
- preview concrete effects.

Do not expose unrevealed secret perks.

## 8. Palace

Palace unlock itself remains 10/10 ordinary Hard Work.

Completing a Palace ending can:
- unlock third Legacy slot;
- unlock Palace-only perks;
- unlock late meta knowledge.

Exact first Palace reward OPEN.

## 9. Acceptance

Meta layer works if:
1. fresh run has no strong perk advantage;
2. first few endings visibly improve start;
3. mid profile can combine two rule changes;
4. late profile is substantially easier;
5. no single perk is mandatory for every goal;
6. loadout persists correctly;
7. switching perks does not alter earned permanent history.
