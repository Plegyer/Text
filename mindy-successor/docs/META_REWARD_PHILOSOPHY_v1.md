# Meta Reward Philosophy v1

Дата: 2026-09-25.

Статус: **TARGET PRODUCT PRINCIPLE / CATALOG OPEN**.

## 1. Core rule

Endings are allowed to make future runs **substantially easier**.

This is intentional progression.

The fresh profile is the hardest ordinary version of the life sim.

## 2. Reward families

Allowed and desirable:

- +daily Energy;
- starting money;
- daily money;
- reduced/free lodging;
- stat carry-over;
- starting stat bonuses;
- starting items/tools;
- profession unlocks;
- School discounts/upgrades;
- Activity equipment/access;
- alternate starts;
- rule changes;
- knowledge/content unlocks.

No blanket ban on universal rewards.

## 3. Power ordering

### Hard Work
Should give a clear useful profession-themed advantage.

It may be numerical.

Because all 10 Hard Work endings are required for Palace, collecting them should progressively smooth ordinary runs.

### Complex career ending
Can give stronger or more unusual advantage than Hard Work.

### Secret/rare ending
Can strongly alter a rule.

### Palace/meta ending
Can be very powerful.

## 4. Stacking

The design should support visible accumulation.

But exact stacking may use:
- automatic permanent rewards;
- selectable Titles/perks;
- limited loadout for especially strong modifiers.

The goal is not to prevent power creep, but to preserve meaningful choices among strong rewards.

## 5. Fresh / mid / late test

Every reward catalog pass must simulate:

Fresh:
- no endings.

Mid:
- ~5 Hard Work + several branches.

Late:
- all 10 Hard Work + Palace access.

Expected result:
late profile has much less survival friction and reaches complex content faster.

## 6. Palace

10/10 Hard Work itself is a long-term progress ladder.

Even before Palace unlock, each new Hard Work should make the next profession easier in some recognizable way.

## 7. Original reference principle

Original Simply Mindy already demonstrates:
- extra Stamina;
- starting money;
- daily income;
- rent removal;
- stat carry-over;
- starting equipment;
- profession unlocks;
- other rule changes.

Successor may use analogous **types** of reward with new values/content.
