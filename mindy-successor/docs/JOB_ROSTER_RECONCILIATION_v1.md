## 2. Почему бар сатиров и таверна остаются разными

Они похожи только поверхностно.

### Служанка в баре сатиров

Системная тема:
- обслуживание;
- личное внимание посетителям;
- управление границами;
- социальная/сексуальная вариативность;
- отношения с постоянными посетителями и персоналом;
- ночные пересечения.

Основной вопрос жизни:
**насколько героиня превращает роль обслуживающего персонала в социальный капитал, личные связи или собственную власть внутри заведения.**

### Таверна/трактир

Системная тема:
- поток путешественников;
- слухи;
- кухня/запасы;
- комнаты и постояльцы;
- сезонный спрос;
- мелкая торговля и посредничество;
- информация из других районов/активностей.

Основной вопрос жизни:
**может ли героиня из работницы общего дома превратиться в хозяйку узла, через который проходят люди, товары и информация.**

Следовательно, MERGE сейчас не нужен.

## 3. Роли десяти ordinary jobs

### J01 — Лесоруб в артели гномов

**Фантазия:** физический труд, бригада, лес, производственный коллектив.

**Главная петля:** смены -> производительность/репутация -> инструменты/лесные проблемы -> лидерство или личная ветка.

**Сильные связи:**
- предметы и инструменты;
- сезонные условия леса;
- охотники/внешняя Activity;
- отношения с бригадой;
- торговец через древесину/контракты.

**Семейства исходов:**
1. Hard Work — остаться надёжной частью артели.
2. Forewoman — получить руководство/долю/собственную делянку.
3. Forest compact — решить внешний лесной конфликт через Activity/магию/охотников.
4. Relationship outcome — отдельная личная линия, если дизайн конкретного NPC этого требует.

**Отличие:** самая понятная физическая профессия, хороший старт для проверки Energy/economy.

### J02 — Служанка в баре сатиров

**Фантазия:** обслуживание в шумном заведении, постоянные посетители, флирт, границы и репутация.

**Главная петля:** обслуживание -> постоянные гости -> выбор стиля поведения -> ночные/relationship ветки -> влияние внутри бара.

**Сильные связи:**
- Похоть/Сексуальность;
- отношения;
- night system;
- школа социальных/сценических навыков;
- слухи от клиентов.

**Семейства исходов:**
1. Hard Work — остаться незаменимой служанкой.
2. Favourite/partner — глубокая личная ветка с конкретным NPC.
3. House power — стать управляющей/совладелицей/центром влияния заведения.
4. Boundary route — сохранить строго профессиональную роль и получить иной статусный результат.

**Отличие:** социально-интимная стартовая профессия; не является generic tavern hub.

### J03 — Помощница на ферме у нежити

**Фантазия:** физический хозяйственный труд + странная магическая биология/нежить.

**Главная петля:** уход/сбор/переработка -> необычные ресурсы -> проблемы неживого хозяйства -> внешние ингредиенты/знания -> преобразование фермы.

**Сильные связи:**
- Magic/Reason;
- школа;
- предметы/ингредиенты;
- large Activity;
- сезонные урожаи;
- торговец.

**Семейства исходов:**
1. Hard Work — остаться частью хозяйства.
2. Research farmer — вывести/освоить новый способ производства через школу.
3. Farm successor — получить контроль/долю в хозяйстве.
4. External quest outcome — решить проблему фермы через предмет/Activity.

**Отличие:** стартовый мост между физическим трудом, магией, предметами и экономикой.

### J04 — Работница таверны/трактира

**Фантазия:** городской/дорожный информационный и хозяйственный узел.

**Главная петля:** смена -> обслуживание потока -> слухи/запасы/постояльцы -> выбор, кому помогать -> собственная сеть контактов.

**Сильные связи:**
- торговля;
- жильё;
- сезонные потоки путешественников;
- охотники/стража/наёмная убийца как посетители;
- предметы и rumours.

**Семейства исходов:**
1. Hard Work — постоянная работница трактира.
2. Innkeeper — получить/купить/унаследовать трактир.
3. Information broker — превратить слухи и связи в отдельную власть.
4. Sanctuary — сделать заведение безопасным домом/убежищем для выбранной группы.

**Отличие:** экономика + информация + cross-job hub, а не личное обслуживание сатиров.

### J05 — Охотница

**Фантазия:** сезонная добыча, следы, риск, знание окраин.

**Главная петля:** контракт -> подготовка/предметы -> вылазка/добыча -> продажа/трофеи -> более редкие цели.

**Сильные связи:**
- большая Activity;
- сезон;
- экипировка/предметы;
- торговец;
- ферма;
- лесорубы;
- стража.

**Семейства исходов:**
1. Hard Work — признанная охотница.
2. Master hunter — закрыть серию сложных сезонных контрактов.
3. Warden — перейти от добычи к защите конкретной территории/существ.
4. Trophy/legend route — редкий результат через крупную Activity.

**Отличие:** профессия сильнее других зависит от внешнего режима и сезона.

### J06 — Стражница

**Фантазия:** городская власть, патрули, кризисы, закон и компромиссы.

**Главная петля:** патруль -> происшествия -> репутация/решения -> доступ к закрытым районам/делам -> повышение.

**Сильные связи:**
- minor-crisis analogue;
- таверна/улица;
- торговец;
- наёмная убийца как противоположная сеть;
- дворец;
- отношения с городскими NPC.

**Семейства исходов:**
1. Hard Work — ветеран стражи.
2. Officer — повышение/командование.
3. Reform/corruption branch — выбрать, какой порядок поддерживать.
4. Major case — раскрыть/решить большую межсистемную цепь.

**Отличие:** профессия превращает повседневные городские события в карьерный ресурс.

### J07 — Гейша / артистка дома искусств

**Фантазия:** искусство, этикет, беседа, выступления, статусные клиенты.

**Главная петля:** обучение репертуару -> выступления/приёмы -> патроны -> социальные обязательства -> влияние/мастерство.

**Сильные связи:**
- школа;
- дворец;
- сезоны/фестивали;
- отношения;
- предметы/наряды;
- торговец.

**Семейства исходов:**
1. Hard Work — признанная профессионалка дома.
2. Master artist — культурное мастерство/собственная школа.
3. Patron route — сложная статусная relationship ветка.
4. Court invitation — профессиональный путь, помогающий открыть/усилить дворцовую карьеру, но не заменяющий meta unlock.

**Отличие:** высокостатусная социально-культурная профессия; её прогресс сильно зависит от школы и календарных событий.

### J08 — Наёмная убийца

**Фантазия:** скрытые контракты, подготовка, наблюдение, риск и морально-прагматические выборы без отдельного morality-stat.

**Главная петля:** получить контракт -> разведка -> выбрать способ -> подготовить предмет/маршрут -> выполнить или изменить заказ.

**Сильные связи:**
- предметы;
- большая Activity;
- торговец/чёрный рынок;
- стража;
- таверна как источник слухов;
- дворец.

**Семейства исходов:**
1. Hard Work — профессионал контрактов.
2. Ghost — элитная репутация через сложные чистые задания.
3. Turncoat/handler takeover — разорвать или захватить собственную сеть заказчиков.
4. Refusal chain — сознательно сорвать ключевые контракты и создать другую судьбу.

**Отличие:** наиболее choice-heavy профессия; успех определяется подготовкой и способом, а не только статовым порогом.

### J09 — Торговка

**Фантазия:** покупать, продавать, замечать спрос, строить сеть и управлять риском.

**Главная петля:** заработать/закупить -> выбрать рынок/сезон -> продать -> расширить доступ к товарам/контактам.

**Сильные связи:**
- почти все профессии как поставщики/клиенты;
- предметная система;
- сезонные цены/дефициты;
- таверна;
- ферма;
- охота;
- дворец.

**Семейства исходов:**
1. Hard Work — устойчивая лавка/место на рынке.
2. Merchant house — крупная торговая сеть.
3. Speculator/smuggler — рискованный путь через дефицит/серые товары.
4. Patron of routes — связать несколько систем поставок и получить статусный результат.

**Отличие:** главная экономика/предметы profession; должна менять способы действий, а не быть shop UI.

### J10 — Проститутка

**Фантазия:** добровольная профессиональная сексуальная работа с агентностью, клиентской сетью и собственной карьерой.

**Главная петля:** выбрать/получить клиентов -> управлять репутацией и границами -> постоянные клиенты/отношения -> более дорогие или статусные возможности.

**Сильные связи:**
- Сексуальность/Похоть;
- отношения;
- night system;
- деньги;
- информация;
- дворец/статусные клиенты;
- health/condition system только если такой meter будет отдельно утверждён.

**Семейства исходов:**
1. Hard Work — стабильная профессиональная жизнь.
2. Independent house — собственное заведение/самостоятельная практика.
3. Elite clientele — статусный путь через сложные social gates.
4. Relationship exit — уйти из профессии в конкретную взаимную линию, если она заслужена.

**Отличие от Secret Slave Career:** добровольность, контроль над выбором работы и клиентов, возможность уйти; отсутствие долгового professional lock.

## 4. Hidden Palace profession

**Дворец** — отдельная поздняя meta-job.

Рабочая гипотеза роли:
- синтез нескольких ранее развитых компетенций;
- высокий статус;
- доступ к политическим/ритуальным/культурным задачам;
- связи с гейшей, стражей, торговцем, убийцей и большой тайной мира;
- несколько дворцовых ролей/веток внутри одной профессии.

Она должна иметь:
- repeatable palace work;
- собственную career state machine;
- минимум 3 исхода;
- события, которые меняются в зависимости от прежних Meta unlocks;
- возможность быть частью большой межжизненной цели.

Не фиксируем пока конкретную должность героини во дворце.

## 6. Общий career skeleton

Для ordinary jobs общий минимум:

```text
available
-> repeatable shifts
-> first personal milestone
-> stat/external gate
-> branch choice
-> repeated/seasonal/relationship progression
-> 3+ ending families
```

Простой Hard Work исход должен существовать отдельно от сложных веток.

Не фиксировать один и тот же shift threshold всем профессиям автоматически: оригинальные 15/50 — полезный референс, но successor может использовать разные темпы после общего balance pass.

## 7. Проверка на дублирование

- Maid vs Tavern: personal service/intimacy vs information/economy hub.
- Farm vs Lumber: magical production/items vs physical production/crew.
- Hunter vs Assassin: open seasonal resource/risk vs targeted covert contracts/choices.
- Geisha vs Prostitute: art/status/etiquette vs explicitly sexual paid work.
- Merchant vs Tavern: market/inventory network vs hospitality/information.
- Guard vs Assassin: institutional public order vs covert private violence.

На этом уровне все 10 имеют отдельную системную роль.
