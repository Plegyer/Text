## Global loop acceptance

For every requested file:
- the loop must reset cleanly without relying on a gameplay timer;
- it must not reveal or select reward, wage, success, failure, route, milestone or event outcome;
- it must not encode a season if the file is reused across all four seasons;
- it must not contain required readable text;
- media must remain meaningful under both RU and EN;
- real source file must land under prototype `assets/` and pass GIF-signature preflight;
- each semantic pool must retain its current static fallback;
- each mapped pool needs 3–5 real candidates before production activation.

These files are not approved for result/event/relationship identities merely because the visual theme is similar. Additional reuse requires semantic review.
