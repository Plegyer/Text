# C2-207 — Assassin contract-flow presentation vocabulary

Status: COMPLETE PREP ONLY
Owner: Chat 2 / Presentation & Media
Authority: `docs/CAREER_ASSASSIN_DRAFT_v0.md`
Production binding: NONE

## Purpose

This file prepares a visual/presentation taxonomy for a possible future Assassin contract flow without reserving gameplay IDs.

Draft sequence:
- offer
- intel gathering
- prep
- choose method
- execute / abort / redirect
- fallout

Every entry below is conceptual presentation vocabulary only.

## Conceptual phases

### Offer
Visual meaning:
- contract handoff;
- sealed note;
- neutral contact;
- location brief;
- incomplete information.

Must not imply:
- accepted contract state;
- payment;
- target identity;
- lethal intent;
- commitment.

### Intel gathering
Visual meaning:
- maps;
- route notes;
- observation;
- timing;
- public-place reconnaissance;
- nonviolent information review.

Must not imply:
- surveillance mechanic;
- tracking meter;
- guaranteed target knowledge;
- Guard wanted state.

### Prep
Visual meaning:
- route planning;
- neutral equipment check;
- clothing/disguise choice;
- document review;
- fallback planning.

Must not imply:
- item grant;
- capability activation;
- combat loadout;
- black-market purchase.

### Choose method
Visual meaning:
- multiple route cards/options;
- distinct social/stealth/staged/indirect/refusal framing;
- clear semantic choice separation.

Must not imply:
- all methods are available;
- method eligibility;
- success odds;
- Morality alignment.

### Execute
Visual meaning:
- committed route/action scene only if a future runtime publishes such a phase.

Preparation guidance:
- keep target-free by default;
- prefer route/environment/aftermath framing over explicit violence;
- do not assume combat.

### Abort
Visual meaning:
- deliberate withdrawal;
- unused route;
- closed note/tool;
- exit path.

Must not present abort as:
- automatic failure;
- punishment;
- Morality gain/loss;
- permanent career lock.

### Redirect
Visual meaning:
- information rerouted;
- alternate contact;
- changed destination;
- evidence passed elsewhere.

Must not imply:
- specific Guard/Palace recipient;
- relationship write;
- automatic Turncoat route.

### Fallout
Visual meaning:
- consequence context;
- changed patrol/crowd/contact atmosphere;
- investigation pressure;
- relationship tension.

Must not imply:
- global fallout meter;
- wanted level;
- crime heat stat;
- reputation system.

## Semantic separation from ordinary Work

These conceptual contract phases must never replace:
- `job/assassin/result/default`
- `job/assassin/shift/<season>/default`

Ordinary Work remains ordinary city-side shift presentation.

## Future ID policy

No production ID is reserved by C2-207.

If a future runtime publishes exact contract-phase identities, Chat 2 may then map them to a dedicated semantic presentation namespace derived from those exact runtime IDs.

Until then, all future contract-flow rows must be marked:
- `PENDING_RUNTIME_ID`

## Firewall

C2-207 creates no:
- contract state machine;
- target;
- combat rule;
- lethal/nonlethal rule;
- Morality stat;
- outcome eligibility;
- relationship write;
- Guard/Palace write;
- Save/RNG;
- economy;
- Activity/NightFlow mechanics.
