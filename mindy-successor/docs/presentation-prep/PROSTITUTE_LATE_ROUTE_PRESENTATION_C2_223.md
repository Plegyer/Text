## Distinction matrix

Independent House:
- center: workplace control / management
- visual axis: room, schedule, keys, administration

Elite Clientele:
- center: selective high-status professional context
- visual axis: formal setting, invitation, curated appointments

Network / Protection:
- center: support/safety/contact network
- visual axis: coordination, contacts, practical protection

These concepts must not collapse into one generic “successful career” presentation family.
