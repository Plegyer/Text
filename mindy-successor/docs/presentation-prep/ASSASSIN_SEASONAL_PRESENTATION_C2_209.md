# C2-209 — Assassin seasonal presentation preparation

Status: COMPLETE PREP ONLY
Owner: Chat 2 / Presentation & Media
Production binding: shipped ordinary seasonal Work only

## Goal

Prepare seasonal visual vocabulary around:
- crowds;
- visibility;
- travel;
- disguise/clothing;
- routes.

These concepts enrich presentation only. They do not create seasonal gameplay systems.

## Spring

Prepared cues:
- wetter streets;
- layered travel clothing;
- busier public routes;
- fresh market/festival setup;
- changing daylight.

Presentation use:
- observation;
- route preparation;
- ordinary equipment handling;
- public-place reconnaissance.

Must not imply:
- Spring-specific success bonus;
- festival contract;
- new event ID.

## Summer

Prepared cues:
- longer daylight;
- denser evening crowds;
- lighter clothing;
- open courtyards/windows;
- increased travel and public movement.

Presentation use:
- route timing;
- public social access;
- visibility planning.

Must not imply:
- automatic NightFlow access;
- crowd mechanic;
- social bonus.

## Autumn

Prepared cues:
- festival traffic;
- layered disguise/clothing;
- shorter daylight;
- deliveries and busy routes;
- indoor/outdoor transition.

Presentation use:
- changing visibility;
- staged public context;
- evidence/document handoff.

Must not imply:
- contest/festival system;
- target opportunity;
- Guard pressure.

## Winter

Prepared cues:
- heavy clothing;
- reduced daylight;
- snow/mud tracks;
- fewer open routes;
- indoor public venues.

Presentation use:
- route planning;
- concealment through ordinary clothing;
- travel constraints represented visually.

Must not imply:
- tracking mechanic;
- weather penalty;
- forced indoor contract.

## Ordinary shipped surface preservation

Current production already has:
- `job/assassin/shift/spring/default`
- `job/assassin/shift/summer/default`
- `job/assassin/shift/autumn/default`
- `job/assassin/shift/winter/default`

These remain the only production seasonal Assassin presentation IDs in v19 prep.

Prepared advanced seasonal vocabulary must not overwrite those ordinary Work cards.

## Disguise boundary

Seasonal clothing/disguise imagery may communicate context fit only.

It must not imply:
- a disguise item exists;
- capability grant;
- universal social access;
- Palace access;
- identity replacement;
- invisibility/stealth status.

## Travel boundary

Travel/route imagery is presentation context only.

It must not create:
- travel action;
- route cost;
- Activity route;
- calendar movement;
- teleportation;
- destination unlock.

## Future binding

Any future advanced seasonal Assassin event must use an exact runtime ID. Until then:
- advanced seasonal event identity = `PENDING_RUNTIME_ID`

## Firewall

C2-209 changes no seasonal conditions/effects, event scheduling, crowd system, visibility system, disguise mechanics, travel mechanics, Save/RNG, Activity/NightFlow, economy, ending eligibility or Meta.
