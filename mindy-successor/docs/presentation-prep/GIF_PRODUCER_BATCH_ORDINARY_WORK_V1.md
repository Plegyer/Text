# GIF Producer Batch — Ordinary Work v1

Purpose: first producer-facing media batch for the 10 ordinary career base shifts now present on current main.

This batch does not choose:
- final art style;
- character appearance;
- camera language;
- named NPC design;
- milestone/ending visuals.

It defines only safe visible action/context briefs.

## Batch rule

For each career:
- semantic identity remains `job/<career>/shift/<season>/default`;
- initial target pool: **4 GIF loops**;
- loops may be reused across seasons where visually appropriate;
- seasonal variants may adjust environment/context;
- GIF choice never changes mechanics or outcome;
- current static fallback remains valid.

## Seasonal adaptation rule

Each career already has:
- spring;
- summer;
- autumn;
- winter

semantic shift surfaces.

The producer may create:
- one neutral base loop reused across seasons;
- one or more seasonal environment variants;
- additional motion variants up to the 3–5 candidate pool limit.

Do not force four unique season-specific animations when shared motion is visually sufficient.

## Delivery card fields per loop

Each delivered GIF should include:
- semantic presentationId(s);
- candidate stable key;
- reusable group if any;
- short visible-context description;
- loop expectation;
- alt/accessibility text;
- static fallback;
- source-content approval reference.

## Batch exclusions

This batch does not cover:
- career events/milestones;
- named relationships;
- Night scenes;
- Hard Work endings;
- Palace;
- Activity challenges;
- Secret Debt.

Those require their own authored semantic identities.

## Acceptance

A loop is acceptable when:
1. it matches ordinary work context;
2. it does not imply a different gameplay result;
3. it can be disabled without affecting play;
4. static fallback remains meaningful;
5. alt text describes only visible presentation;
6. no filename or visual candidate becomes gameplay identity.
