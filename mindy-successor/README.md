# Mindy Successor Project

Рабочая память проекта. Здесь идут две параллельные задачи:

1. Разобрать системный дизайн Simply Mindy настолько, насколько это полезно для нового проекта.
2. Собрать самостоятельную игру с другим миром, сюжетом, персонажами, визуалом и позднее — другими мини-играми/вложенной игрой.

Оригинал используется как источник проверенных игровых принципов, а не как контент для прямого копирования.

Главный файл состояния: docs/PROJECT_STATE.md
Прямые находки из SWF: docs/ORIGINAL_CORE_FINDINGS.md
Зафиксированный каркас новой игры: docs/NEW_GAME_SPEC_v0.md
